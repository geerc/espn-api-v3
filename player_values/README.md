# Current-season KTC working files

Weekly CSVs here are disposable current-season ESPN inputs. The 2025 files were purged before the 2026 season; prior copies remain recoverable in Git history. At season rollover remove the old weekly CSVs before scraping the new season. Do not reuse a previous season's file for the same week number.

This is separate from SYPIP's archived report snapshots, which preserve the data associated with reviewed reports.
